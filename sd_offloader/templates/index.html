After Start auto offload, keep the session running — new SD cards are detected by structure (DCIM → xxxGOPRO → MP4 + JSON), not by card name. A card never splits across SSDs. Each disk uses its own batch number. Failures stay on screen with Retry (resumes; already-copied files are skipped). Mid-copy removal marks the card interrupted (Retry after re-insert). Cancel stops without wiping the card.

AWS uploads (batches)

In SSD + AWS mode, a batch is closed for new cards when the disk cannot take the next card (10 GB reserve) or when you click Batch Completed. Closing does not delete the folder and does not mean AWS is done — older closed batches upload, verify, and clean up independently while the new active batch keeps receiving cards. Both SSDs still start at the same cycle number and only advance on their own disk. After Upload this SSD to AWS or Batch Completed, a successful size verify deletes only that SSD's batch folder (the other SSD and other batches stay). Same filename on two SSDs becomes GX010001-1.MP4 on S3 instead of overwriting.
