AWS uploads (batches)

In SSD + AWS mode, when a disk cannot take the next card with the 10 GB reserve, that disk’s batch is frozen and s5cmd syncs it while the other disk keeps ingesting. After two matching size checks, that batch is deleted on that disk only and the next cycle number opens on that disk (both SSDs use batch01, then both use batch02 — they do not skip ahead of each other). Upload this batch to AWS still works for batches that are not full (night). Verify, then Delete local only when verified.
